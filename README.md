# 🎖️ War Spectra Discord Bot

> ⚠️ **ПРИВАТНЫЙ РЕПОЗИТОРИЙ** — Код принадлежит проекту **War Spectra**. Несанкционированное копирование и распространение запрещено.

Внутренний Discord-бот для автоматизации процессов игрового проекта War Spectra (Arma 3).

---

## 🛠️ Стек технологий

* **Language:** TypeScript / Node.js
* **Framework:** Discord.js v14 + CommandKit
* **Database:** Sequelize (MySQL)

---

## 🔑 Разворачивание (Только для разработчиков проекта)

### 1. Клонирование и установка зависимостей

```bash
git clone 
cd war-spectra-bot
npm install

```

### 2. Настройка окружения

Скопируйте файл `.env.example` в `.env` и заполните переменные окружения (актуальные тестовые ключи запросите у администратора):

```bash
cp .env.example .env

```

Структура `.env`:

```env
DISCORD_TOKEN=
CLIENT_ID=
GUILD_ID=
DB_HOST=127.0.0.1
DB_NAME=
DB_USER=
DB_PASSWORD=

```

### 3. Запуск

```bash
npm run dev # Для разработки (TSNode / Nodemon)
npm run build && npm start # Сборка и запуск в продакшене

```
